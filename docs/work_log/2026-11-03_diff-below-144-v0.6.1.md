# 2026-11-03 — The /diff buttons work below 144 columns (v0.6.1)

## Context

The user asked for the `/diff` buttons to work on terminals under 144
columns. v0.6.0 (`2026-11-03_dock-diff-switch-v0.6.md`) documented that a
button's `/diff` was refused there until the person had typed `/diff` once.

## Files changed

- `plugins/mark-mod/hooks/register.tsx` — `DIFF_SEND_TEXT`, `DIFF_TYPE_TEXT`; `handDiffToPerson` puts `/diff` in an empty prompt box with `$.prompt.fill` and toasts, or toasts to type it when a draft is there; `runDiff` reads whether the session pane is in front before and after an idle run and hands over when a run that answered text left it in front; `CommandRunResult` import.
- `plugins/mark-mod/tests/dashboard.test.tsx` — `DiffOutcome` (`shown`, `hidden`, `refused`, `silent`) and `DIFF_ANSWERS`; world gains `diffOutcome` and `draft`, the `diff` run moves the pane behind or in front as each outcome would, hooks for `prompt.read` and `prompt.fill`; 5 tests.
- `README.md` — "If the panel does not come up" bullet; the hidden-tab and 144-column bullets and the Troubleshooting entry now describe the hand-over.
- `docs/design.md` — the asked rule as the engine applies it, and a hand-over paragraph.
- `plugins/mark-mod/.claude-plugin/plugin.json` — 0.6.1.

## Why

- **The cause is the engine's asked rule, and no plugin call changes it.** In 2.1.317 `ui.open` passes `$D(caller)` as the asked flag: true only when the origin chain is one hop from the person (`isPersonInput`) or the root event is a `ui.press`, `ui.input` or `ui.select` the opening plugin handled. A press here → `$.command.run` → the diff plugin's `$.ui.open` is two hops, so the open is unasked and seats from 144 columns (`jAt`), or 110 (`iae`) for an id in `~/.claude.json` `pluginPanes.asked`. A person's close (`origin.kind === "person"`) removes it from that list (`forgetAsked`). `CommandRunArgs` leaves `origin` to the engine and `$.prompt.submit` is a plugin's prompt too, so the only asked path is the person's own `/diff`.
- **Hand the command to the person only when the run failed.** One click stays one click whenever the engine allows it (from 144 columns, or from 110 once asked). The failure signal is the session pane's own `isShown`, read before and after: a shown panel puts the `Diff` tab in front. Not the answer's wording. The same check covers v0.6.0's hidden-tab case (the run closes a `Diff` tab behind the pane), which needed the same remedy.
- **Excluded: queued runs, the sidebar, drafts.** A run queued behind a turn starts after the person may have switched tabs, so it is not checked. The older sidebar leaves the covered pane reading shown but answers no text, so a run without text is never taken for a failure. A draft is never replaced; the toast asks the person to type `/diff`.
- **Rejected:** writing `pluginPanes.asked` in `~/.claude.json` (the engine's record of the person's choice, written by the engine at the same time); matching "Resize your terminal…" (engine prose); always filling the prompt below 144 columns (two steps even when one would work).
